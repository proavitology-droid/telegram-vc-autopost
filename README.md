# Telegram → vc.ru

Перенос новых постов из канала «ОтЧАЙный Авитолог» в блог vc.ru. GitHub Actions запускает проверку раз в час, а Chrome открывается при наличии новой записи. Очередь хранит номера записей, чтобы при повторном запуске не появлялись дубли.

## Подключение

1. Проверьте бесплатный лимит GitHub Actions в Billing and licensing. Если к аккаунту привязана карта, установите бюджет для Actions с остановкой использования при достижении лимита. Сценарий рассчитан на стандартный Linux-раннер и ограничен двумя минутами на запуск.
2. Один раз запустите `connect.py` на компьютере с Python 3.10+, Google Chrome и GitHub CLI. Из папки репозитория выполните `python -m pip install -r requirements.txt`, `gh auth login`, затем `python connect.py`. В окне Chrome войдите на vc.ru в блог «ОтЧАЙный Авитолог». Состояние входа попадёт напрямую в секрет `VC_STORAGE_STATE` в GitHub Actions. Скрипт держит его в памяти до передачи.
3. В разделе **Actions → Telegram → vc.ru → Run workflow** запустите режим `draft`. Откройте ссылку из журнала и проверьте текст, ссылки и фото. Черновик создан для проверки и его можно удалить после теста.
4. Запустите `initialize`. В журнале будет номер последнего поста, который станет точкой начала. После этого расписание будет проверять новые записи на 17-й минуте каждого часа. Режим `publish` позволяет запустить цикл вручную.

Если vc.ru запросит вход, повторите второй шаг. Если после отправки не удалось подтвердить публикацию, сценарий проверит блог перед повтором. Остановить расписание можно в меню сценария в разделе **Actions**. Ссылки на записи с вложениями, требующими ручной проверки, находятся в `state.json` в поле `review`.
